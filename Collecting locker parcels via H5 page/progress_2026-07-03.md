### 1. PIN as the baseline auth flow
- New **PIN FLOW** as the default: scan → enter 6-digit Collection PIN → parcel preview. One-time, no token persistence, wrong-PIN shows inline error only (rate-limiting is existing BE logic, out of scope).
- Demo helper: entering `000000` triggers the error state; any other 6 digits succeed.
- Renamed/repurposed the old **FIRST-TIME** tab; then **removed the "TOKEN SETUP" tab entirely** (redundant once the token option is reachable from the PIN screen + controlled by the market toggle).
- **"Collect for other buyers"** now routes to a PIN-entry screen for the *other* buyer's PIN (copy adjusted, token upsell hidden) — not token setup.

### 2. Token-setup consent screen (`stepTokenConsent`)
- New explainer step between the PIN screen's "Set up phone verification instead" link and the phone-input screen.
- Outcome-first title "Turn this phone into your locker key", 3 plain bullets (no PIN / works at any SPX Locker / this phone only), red shared-device warning, consent statement + T&C link, "remove anytime from Shopee app" mention.
- Consent gate = explainer + self-describing CTA ("I understand — set up this phone"). Scope confirmed **all SPX lockers** (copy reconciled from "this locker" to "any SPX Locker" throughout).
- Error-prevention back-outs ("Use a PIN instead") added on both the consent screen and the phone-input screen, styled consistently with the OTP "Back to Phone Input" button.
- Removed the arbitrary key icon at the top of the consent screen.

### 3. Copy fixes
- Phone-input CTA "FIND MY PARCELS" → **"VERIFY PHONE NUMBER"** (BRD 3.2; honestly describes sending the OTP).
- COD flow CTA fixed: preview button now shows **MAKE PAYMENT** (BRD 3.3 pt 7) instead of "COLLECT ALL NOW"; non-COD flows keep "Collect All Now". Driven by `currentFlow` swapping the button's `data-i18n` key.

### 4. TW collect-screen variant (`H5_TW_collect_list.html`)
- Per Eva Wan's BRD comment: TW shows **cell ID + SPX TN list, no visual compartment layout**.
- Standalone screen mirroring the standard collect UI (header, stats, Reopen Door / Collected All, reopen dialog); grid replaced with cell-ID-badge + TN rows (two rows share A01 to show multiple parcels per cell). Kept the "many parcels in 1 locker" + "close all doors" reminders.
- Note: council pushed back on stripping the visual layout (wayfinding risk); Gareth is waiting on TW team's current UI before finalizing.

### 5. Language switcher
- Persistent top-right switcher inside the phone, mirroring the locker-screen PRD model ([All ex TW] Locker UI Enhancement): per-market default + options, session-scoped, resets to market default on fresh scan.
- SG option set shown (English default + 中文 / Bahasa Melayu / தமிழ்). Built as a proper `data-i18n` + dictionary pattern; key strings (PIN screen, preview CTAs, collect CTAs) translate live.
- **Non-English copy is illustrative placeholder only** — production copy comes from Transify per market (noted in code comment).

### 6. Layout
